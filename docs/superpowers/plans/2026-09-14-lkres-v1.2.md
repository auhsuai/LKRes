## Dữ liệu đã research (Toshiba datasheet gốc — ảnh chụp trực tiếp, xem "Nguồn")

Pinout đọc theo **hướng nhìn mặt có chữ, chân hướng xuống**, trái → phải:

| Tên in vỏ | Tên đầy đủ | Loại | Vỏ | Chân 1 (trái) | Chân 2 (giữa) | Chân 3 (phải) |
|---|---|---|---|---|---|---|
| C1815 | 2SC1815 | BJT NPN | TO-92 | E — cực phát (Emitter) | C — cực thu (Collector) | B — cực nền (Base) |
| A1015 | 2SA1015 | BJT PNP | TO-92 | E | C | B |
| K30A | 2SK30A | JFET kênh N | TO-92 | S — cực nguồn (Source) | G — cực cổng (Gate) | D — cực máng (Drain) |

- C1815 khớp đúng mô tả user (E-C-B). A1015 cùng template Toshiba TO-92 (2-5F1B) với 2SC1815 (complementary pair) → E-C-B. K30A theo 2SK30ATM: 1.SOURCE 2.GATE 3.DRAIN; cùng template mechanical drawing với 2SC1815 (đã cross-check trực quan 3 datasheet) → S-G-D.

**Interfaces (Task 28 dùng — CHỐT CỨNG):**
```kotlin
enum class ComponentCategory(val label: String) { BJT("BJT"), FET("FET") }

data class ComponentPin(val symbol: String, val function: String) // symbol: "E", function: "cực phát (Emitter)"

data class Component(
    val name: String,        // "C1815" — tên in trên vỏ (dùng làm id)
    val fullName: String,    // "2SC1815"
    val category: ComponentCategory,
    val kind: String,        // "BJT NPN" / "BJT PNP" / "JFET kênh N"
    val packageName: String, // "TO-92"
    val pins: List<ComponentPin>, // đúng 3 phần tử, thứ tự trái→phải theo hướng nhìn mặt chữ
)

object ComponentCatalog {
    val all: List<Component>
    fun byCategory(category: ComponentCategory): List<Component>
    fun search(query: String, category: ComponentCategory? = null): List<Component>
}
```
- `search`: trim + uppercase; query rỗng/toàn khoảng trắng → `emptyList()` (UI tự xử lý hiển thị khi rỗng). Khớp `contains` trên 4 field text: `name`, `fullName`, `kind`, `category.label`. `category != null` → chỉ tìm trong danh mục đó.
- Data 3 linh kiện đúng bảng research ở trên; pins dùng đúng symbol + function tiếng Việt.
